OpenAPI Spec

The Watermarks Remover engine runs entirely as a Python stdlib-first local server. Optional system binaries (ExifTool, C2PATool, QPDF, Ghostscript, FFmpeg) enhance container parsing when installed on the host.

Privacy & Security Contract

  • All sanitization occurs in volatile memory and ephemeral local buffers. No telemetry or external analytics.
  • Layer A strictly strips covert provenance signals while maintaining exact document structure, paragraphs, and styling.
  • Adheres to ethical ownership principles: designed for sanitizing content that you rightfully own or are authorized to process.
